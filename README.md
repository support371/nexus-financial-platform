# ApexTrust Banking

Institutional-grade white-label bitcoin banking demo focused on compliance transparency, operational accountability, and service-quality assertions.

## Quick start (single-file MVP)
1. Clone repository.
2. Open `app/index.html` in your browser (or serve repo root with any static server).
3. Use seeded admin login:
   - `admin@apextrust.bank`
   - `admin123`

## Core docs
- `SPEC.md` — authoritative requirements and acceptance criteria.
- `AGENT_TASKS.md` — phase-based execution plan.
- `DEPLOYMENT.md` — release/deploy tracking template.
- `docs/TEST_PLAN.md` — manual smoke checklist.

## Current architecture
- **MVP:** single-file web app at `app/index.html` with embedded CSS/JS and localStorage persistence.
- **Future path:** migrate to full stack (frontend + API + database + hosted auth) after product validation.
