# ApexTrust Banking Agent Task Plan

## Mission
Deliver an institutional-style, single-file MVP demo that showcases transparent compliance posture, accountable operations, and user-verifiable service quality.

## Phase 1 — Foundation and Branding
- Apply global rebrand to ApexTrust Banking.
- Enforce naming conventions (`APT-`, `apextrust_*`).
- Define requirements in `SPEC.md`.

## Phase 2 — Core Client Journeys
- Landing + authentication flow.
- Signup auto-provisioning (profile, role, region account, reference code).
- Dashboard with derived ledger KPIs.
- Accounts and Deposits flows with quote expiry + memo requirement.

## Phase 3 — Trust Controls
- KYC workflow + admin approval simulation.
- Card issuance eligibility gates + card controls.
- Compliance Center with posture + SLA KPIs.
- Ratings/assertions with aggregation.

## Phase 4 — Governance and Audit
- Admin surfaces for clients/deposits/cards/KYC/compliance.
- Incident register and lifecycle simulation.
- Append-only audit log with tamper-evident integrity check.
- JSON exports: transparency, compliance, incidents, ratings, audit.

## Phase 5 — QA and Release Readiness
- Run smoke checklist across all pages.
- Validate no console errors in normal usage.
- Record deployment info in `DEPLOYMENT.md` template.
